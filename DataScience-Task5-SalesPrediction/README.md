# 📊 Sales Prediction Using Python

## 📌 Project Overview

This project focuses on predicting product sales based on advertising expenditure across different media channels such as TV, Radio, and Newspaper.

A machine learning regression approach is used to understand the relationship between advertising spending and product sales.

## 🎯 Objective

To build a regression model that predicts product sales using advertising spend across:

* TV
* Radio
* Newspaper

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📂 Dataset

The project uses the `Advertising.csv` dataset.

### Dataset Features

| Feature   | Description                          |
| --------- | ------------------------------------ |
| TV        | Advertising expenditure on TV        |
| Radio     | Advertising expenditure on Radio     |
| Newspaper | Advertising expenditure on Newspaper |
| Sales     | Product sales                        |

## 🔍 Project Workflow

1. Load the dataset
2. Perform data inspection
3. Check for missing values
4. Generate descriptive statistics
5. Perform Exploratory Data Analysis (EDA)
6. Create pairplots
7. Create individual scatter plots
8. Analyse the correlation matrix
9. Split data into training and testing sets
10. Train a Linear Regression model
11. Train a Random Forest Regressor
12. Evaluate the models using MAE, RMSE, and R² score
13. Compare model performance
14. Create a residual plot
15. Analyse advertising channel importance
16. Select the best-performing model

## 📊 Machine Learning Models

### 1. Linear Regression

Linear Regression is used as the baseline regression model.

### 2. Random Forest Regressor

Random Forest Regressor is used as an additional machine learning model for comparison.

## 📈 Evaluation Metrics

The models are evaluated using:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score

## 💡 Expected Outcome

The project aims to identify the relationship between advertising expenditure and sales and determine which advertising channel has the highest impact on product sales.
