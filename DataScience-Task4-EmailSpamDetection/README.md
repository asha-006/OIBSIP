# Email Spam Detection with Machine Learning

## Objective

To build a machine learning model that classifies SMS messages as Spam or Ham using Natural Language Processing (NLP) and TF-IDF feature extraction.

## Dataset

SMS Spam Collection Dataset.

The dataset contains two classes:

- Ham – legitimate messages
- Spam – unwanted or promotional messages

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- NLTK

- Jupyter Notebook

## Techniques Used

- Data Cleaning

- Stopword Removal
- TF-IDF Vectorization
- Train-Test Split
- Multinomial Naive Bayes
- Logistic Regression
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- WordCloud

## Machine Learning Models

### 1. Multinomial Naive Bayes

Used as one of the primary classifiers for spam detection.

### 2. Logistic Regression

Used as a second classifier to compare model performance.

## Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Result

The performance of Multinomial Naive Bayes and Logistic Regression was compared using the evaluation metrics. The better-performing model can be selected based on the obtained results.

## Conclusion

The project demonstrates how Natural Language Processing and Machine Learning can be used to classify SMS messages as Spam or Ham. TF-IDF was used to convert text into numerical features, followed by machine learning classification and performance evaluation.
