# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment trends in India using Python. The analysis focuses on regional variations, monthly trends, state-wise unemployment patterns, and the impact of the COVID-19 pandemic.

## Objective

To perform Exploratory Data Analysis (EDA) on unemployment data in India and identify regional and temporal trends, with a focus on the impact of the COVID-19 pandemic on unemployment rates.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Dataset loading and inspection
* Data cleaning and preprocessing
* Date conversion
* Region-wise unemployment analysis
* Month-wise unemployment trend
* Three-state time-series analysis
* Top 10 regions by unemployment rate
* Correlation heatmap
* Pre-COVID vs Post-COVID comparison
* Data visualization

## Key Findings

The analysis identifies differences in unemployment rates across regions and time periods. The visualizations help understand unemployment trends and highlight changes observed during the COVID-19 period.

## Project Files

* `Unemployment_Analysis.ipynb` — Jupyter Notebook containing the complete analysis
* `Unemployment in India.csv` — Dataset used for analysis

## Conclusion

This project demonstrates how Python-based data analysis and visualization techniques can be used to explore unemployment patterns in India and understand changes across regions and time periods.
